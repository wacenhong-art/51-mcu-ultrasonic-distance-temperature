# 实验三：超声波测距、温度补偿与报警

## 当前接线与选用程序

- 用户已确认 DS18B20 插在板载插座；按厂商程序使用 P3.7。
- 选用 firmware/improved_board.hex。基础版 basic.hex；仅当传感器实际外接 P2.6 时使用 improved_p26.hex。
- 板载 11.0592MHz 晶振，12T 模式。Keil 三版本编译及链接均为 0 警告、0 错误，详见 evidence/build.log。

## 显示和操作
左四位为 XX.X cm，第四位平时熄灭；例如 25.6 表示 25.6cm。K1 每按一次切换距离锁定，第四位 L 表示已锁定。锁定仅冻结距离显示，测量、真实距离报警与温度采集继续运行。
右四位显示摄氏温度，如 25.3。首次转换约一秒，温度缺失或 CRC 错误显示 ----，此时距离暂用 340m/s。温度有效时按 v=331.4+0.6T 补偿。
距离有效显示范围 2.0~99.9cm；超出范围或回波超时显示 ---，不冒充零距离。实际距离大于 0 且小于 10cm 时报警。不要按矩阵键盘，以免影响共用 P1 的超声波引脚。
烧录若无法联机，检查板上 UART 下载跳帽是否恢复连接；断电后操作跳帽。K1/P3.1 与 UART 共脚，若下载电路干扰按键，再断电移除对应 UART 跳帽后运行。

## 验收
1. 用平整硬物正对探头，依次放在 5、10、20、40、80cm，观察左四位。
2. 5cm 应报警；10cm 边界附近可能因测量误差变化，20cm 应安静。
3. 按 K1，移动障碍物：距离显示保持，报警仍跟随实际测量；再按 K1 恢复。
4. 右四位应显示合理室温；轻触 DS18B20，观察读数缓慢变化。---- 表示未读到有效温度。
5. 同一标尺位置分别烧录 basic.hex 与 improved_board.hex，记录补偿前后读数。

编译完成不代表硬件验收完成。2026-11-16：用户确认测距与蜂鸣工作正常；修正 DS18B20 采样时序并再次烧录后，用户确认温度已显示。具体读数、标尺误差和K1锁定仍待记录。

## 温度读取修复
已修正初版1-Wire采样前调用32位运算延时而错过采样窗口的问题。固定NOP采样路径经生成汇编检查约11.94μs，烧录后用户确认温度恢复显示。依据：[DS18B20原厂数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf)。详见 evidence/温度时序回归.txt 与 evidence/温度修复烧录与验收.json。
